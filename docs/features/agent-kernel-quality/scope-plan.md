# P0-1A：可重复执行的内核能力缺口基线

[FRAME | HIGH] 准入结论：`TDD_INPUT_READY`。用户已授权顺序交付；本切片仅建立本地离线诊断基线。最高风险 P1：错误的通过判定掩盖内核缺陷。

## 范围与依据

[KNOWN | HIGH] 当前 Analyzer 将 `forbidden_claim` 的语义检查作为诊断；`NOT_EVALUATED` 不参与 case pass（`evaluation/gates.py`、`evaluation/analyzer.py`）。因此现有 GRR 不得用作正确解答率。P0-1B 单独解决质量口径，不在本切片改变现有 formal campaign 的评判契约。

[FRAME | HIGH] 本切片新增开发用诊断命令和 synthetic fixtures，复用 `ExploratoryProbeResult` 与现有 artifact writer。固定五个探针调用现有 Control Plane 公共入口；仅模型、KSS 等外部能力使用固定替身。无真实网络、凭证、环境文件、生产数据或生产状态变更。

## 验收

1. 每个探针都实际执行，输出预期、有限的观测事实和状态；探针异常只记录安全错误码。
2. 判定器有应通过和应失败对照。pytest 检查测量及报告行为，不锁定“缺陷必须继续存在”，不用 xfail 或 skip。
3. 独立命令整体失败时退出 1，保留所有探针结果；报告文件存在不代表能力通过。测量基础设施失败使用明确的错误结果。
4. 记录探针版本、代码输入摘要、本地 synthetic 范围。报告无生产准入、质量率或任务完成率断言。
5. 运行相关回归、静态检查和独立 Review；将当前未满足项逐项映射到后续切片。基线由事实自然转绿，不能通过改变预期值“修复”。

## 风险、决策与回滚

[FRAME | HIGH] 选择单独的本地诊断命令，避免改变现有 campaign release 语义。公共 Agent/KSS 契约、存储、权限、模型输出规则保持本切片原有行为；不需新增领域 ADR。不会修改 `.env`、依赖或部署配置。回滚范围仅新增的诊断实现、fixture、测试及相关文档，不涉及数据库迁移或外部状态。

[INFERRED | HIGH] 固定样本只能证明对应行为，不能估计总体正确率；外部模型、KSS 和长任务恢复另需真实依赖验证。P0-1A 的工具提前结束问题尚未直接覆盖，复合任务探针先覆盖相同主循环的多次检索路径。

[KNOWN | HIGH] 本版本使用完整词项的固定事实匹配，不是通用语义判定器；同义改写或等值金额的不同表示可能需要更精确的后续标注。结构化事实还必须同时出现在 Accepted Evidence 和末次答案请求的来源集合中；会话摘要必须已准入。源码摘要覆盖 `proof_agent/**/*.py`、离线 fixture YAML/JSON、命令脚本和 `uv.lock`，不表示已核验安装环境或依赖服务版本。
