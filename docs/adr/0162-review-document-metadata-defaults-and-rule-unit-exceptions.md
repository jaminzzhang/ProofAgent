# Review document metadata defaults and Rule Unit exceptions

[FRAME | HIGH] Hybrid metadata review uses one mandatory Document Metadata Default Review bound to the exact document revision and complete canonical anchor-set identity, plus Rule Unit Metadata Override Reviews only for divergent, uncertain, conflicting, or operator-designated anchors. Knowledge Source publication materializes complete Approved Insurance Rule Metadata for every Rule Unit rather than resolving inheritance at retrieval time, and any document revision or anchor-set change invalidates the prior default approval. This keeps runtime authority deterministic while avoiding hundreds of repeated approvals for identical metadata in structurally complex documents.
