# Make Reviews a task-oriented metadata workspace

[FRAME | HIGH] The Knowledge Source Reviews tab becomes a Metadata Review Workspace with authoritative summary, document selection, structured Document Default editing, filterable Rule Unit Overrides, a citation-linked inspector comparing parser baseline and current draft, explicit save/approve/reject actions, and bounded selected-set approval. Profile-backed controls replace the Corrections JSON textarea, Workbook round trip moves to a secondary bulk-edit panel, and historical plus Legacy V1 records remain collapsed and read-only. Publication Readiness blockers deep-link to the exact document and filtered task rather than dropping operators on a generic list.
