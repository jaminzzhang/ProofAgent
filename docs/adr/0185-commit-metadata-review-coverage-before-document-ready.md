# Commit metadata review coverage before Document Ready

[FRAME | HIGH] A Document Revision governed by a Knowledge Metadata Scheme becomes Ready and joins the candidate only through one fenced Metadata-Ready Document Commit that makes its exact completed build, parser proposal lineage, complete anchor-covering Current Review Set, review generation and summary, Source revision, and durable operation outcome visible together. Missing business values create `needs_input` reviews, while transient Review Set materialization remains a retryable finalizing stage and never exposes Ready. Immutable S3 artifacts written earlier remain non-authoritative until this PostgreSQL visibility transaction. A ready insurance candidate with zero or incomplete review coverage is invalid and fails closed.
