# Dashboard Hybrid management stops at Source publication

[FRAME | HIGH] Dashboard manages the production Hybrid Index Knowledge Source lifecycle through explicit Source publication and then shows the resulting Agent binding upgrade opportunity. It does not activate a production Agent Version because that transition requires candidate-bound Phase F evidence and the controlled Agent release workflow; combining the two would let an ordinary Source configuration action appear to bypass release authority.

[FRAME | HIGH] Hybrid Source detail separates Overview, Documents, Reviews, Versions & Publish, Operations, Provider & Health, and Audit so document lifecycle, business approval, asynchronous work, publication, deployment readiness, and audit do not collapse into one status panel. Provider and action capability projections govern content and affordances; rendering a tab never authorizes a command.
