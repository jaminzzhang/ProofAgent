# Preview Profile upgrades and reapprove semantic changes

[FRAME | HIGH] Changing a Source's Insurance Metadata Profile Revision first creates a non-authoritative Metadata Profile Upgrade Preview. Stable IDs with unchanged constraints carry forward, label-only changes remain ready for renewed approval, explicit replacement IDs are suggestions requiring confirmation, removed unmapped values become missing, and incompatible taxonomy, precedence, or date constraints block for input. Only an exact, fresh Apply changes the Source binding and creates new current Review revisions; every affected value requires renewed approval, prior approvals remain historical, and existing published versions retain their pinned Profile revision.
