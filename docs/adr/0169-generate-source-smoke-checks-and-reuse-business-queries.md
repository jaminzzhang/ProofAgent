# Generate Source smoke checks and reuse business queries

[FRAME | HIGH] Knowledge Source publication preparation no longer accepts an ad hoc operator-authored smoke query. A mandatory System Retrieval Smoke Check is generated deterministically from current candidate authority and validates provider-specific retrieval, authorization, and citation behavior, while a versioned Source Verification Query Set supplies reusable business questions when configured or required by deployment policy. Dashboard shows both inputs and their results but does not ask the operator to retype a query for each Prepare command; broader Agent behavior quality remains governed by Agent validation and release gates.
