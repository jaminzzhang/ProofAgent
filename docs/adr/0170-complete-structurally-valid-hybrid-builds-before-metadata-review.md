# Complete structurally valid Hybrid builds before metadata review

[FRAME | HIGH] A Hybrid document becomes a Metadata-Reviewable Hybrid Build when its validated original, structured artifact, canonical Rule Unit anchors, citations, and integrity checks are trustworthy, even if parser-proposed business metadata is incomplete, uncertain, or conflicting. Missing governed metadata creates current `needs_input` reviews instead of a failed ingestion result. Untrustworthy Rule Unit boundaries, table reconstruction, or citation lineage remains a Documents-stage Hybrid Structural Review Required condition, and security, integrity, or technical failures remain failed ingestion outcomes; neither Dashboard editing nor workbook import can repair or bypass structural authority.
