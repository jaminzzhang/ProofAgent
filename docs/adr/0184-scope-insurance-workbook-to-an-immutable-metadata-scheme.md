# Scope Insurance Workbook to an immutable metadata Scheme

[FRAME | HIGH] Every Knowledge Source selects an immutable server-advertised Knowledge Metadata Scheme at creation, and only `insurance_rule.v2` requires an Insurance Metadata Profile Revision, Document Default plus Rule Unit Override review, and Insurance Rule Metadata Workbook V2. A Provider Capability may explicitly allow no Scheme, in which case Metadata readiness is `not_required` and insurance controls are absent. Clients cannot invent Schemes, and changing Scheme requires a new Source rather than reinterpreting historical documents; exact Profile revision upgrades remain permitted within the insurance Scheme.
